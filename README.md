# 🎓 Student Grade Calculator

## 📌 About the Project
The Student Grade Calculator is a beginner-friendly Python project that calculates a student's total marks, percentage, and grade based on marks obtained in different subjects.

## ✨ Features
- Accepts marks for multiple subjects.
- Calculates total marks.
- Calculates the overall percentage.
- Assigns a grade based on the percentage.
- Displays the student's academic performance.

## 🛠️ Technologies Used
- Python 3

## 🚀 How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   `python app.py`

5. Enter the required marks when prompted.

## 🎯 Objective
To simplify grade calculation and demonstrate basic Python concepts, including variables, user input, arithmetic operations, and conditional statements.
